# Sarbottam Bhagat — Academic & Applied Data Science Website

Jekyll website for https://sarbottambhagat.github.io

## Local preview

Install Ruby, Bundler, and Jekyll, then run `bundle install` and `bundle exec jekyll serve`. Open http://localhost:4000.

## Publishing

Review the draft pull request and merge into `main` only when ready. Configure GitHub Pages to deploy from `main` / root.

## Updating

Edit Markdown pages for content and `assets/css/style.css` for styling. No private data, student work, or unpublished project code is included.
