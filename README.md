# Sarbottam Bhagat | Academic Website

Personal academic website of **Dr. Sarbottam Bhagat**, Associate Professor of Information Systems and Business Analytics at the University of Wisconsin–Eau Claire.

🌐 **Website:** https://sarbottambhagat.github.io

## About

This website brings together my academic research, teaching, curriculum development, applied data science projects, professional engagement, and writing.

My interests include information quality, human–AI interaction, AI-assisted decision-making, machine learning, and the responsible application of emerging technologies.

## Website Sections

- **Research** — Research interests, scholarly publications, and funded projects.
- **Data Science & AI** — Applied analytics, machine learning, and AI projects.
- **Teaching** — Teaching areas, curriculum development, and educational initiatives.
- **Engagement** — Professional service, collaboration, and academic engagement.
- **Perspectives** — Articles and reflections published on LinkedIn.
- **About Me** — Academic background, personal interests, and contact information.

## Built With

- GitHub Pages
- Jekyll
- HTML, CSS, and Markdown

## Local Development

To preview the website locally, install Ruby, Bundler, and Jekyll, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000` in your browser.

## Updates and Deployment

Website content is maintained through Markdown files, with shared layout and styling managed through Jekyll templates and CSS.

Changes are published through GitHub Pages from the `main` branch.
